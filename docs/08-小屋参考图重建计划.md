# 小屋参考图重建计划

## 目标与依据

以用户 2026-11-13 提供的 `1000024738.jpg` 为唯一视觉依据。上一轮浅杏色墙、棕色屋顶方案停止迭代。目标是在现有 Three.js 三层空间中还原参考图可见的小屋，不重写书信、音乐、日历、配对业务。

参考图显示左侧墙与正面，镜头较低；原木立板、灰色薄屋瓦、浅木色深出檐、中央三角窗、黑色细窗框、带百叶烟帽的烟囱、木露台、奶油色坐垫。前景大树与密集花草包围房屋，中远景树林形成纵深。暖色主要来自木材、侧逆光与室内灯光，而非整体橙色滤镜。

单张图不能确定真实尺寸、背面和内部。尺寸采用相对比例拟合，保留现有客厅与窗边书桌布局，并保持内外窗户、入口位置一致。不得声称已恢复原图未显示的信息。

## 分阶段交付

| 阶段 | 实施内容 | 验收依据 |
| --- | --- | --- |
| 1 建筑与视角 | 左前方低机位；较窄正面与较深侧墙；独立外饰面；正面玻璃入口、左侧窄窗、三角窗；出檐、烟帽与露台摆设 | 同一取景的运行截图；轮廓、可见侧面、入口、窗与家具关系接近参考；三个空间仍连通 |
| 2 材质与光照 | 真实木板纹理、低色差灰瓦、细窗框、家具细节；主光与补光分别调试；接触阴影 | 木材纹理尺度合理；阴影有层次；亮部保留纹理；室内外材质一致 |
| 3 植被与环境 | 植物素材筛选、近景树干与枝叶、中景灌木、远景林带；分簇花园、小路 | 前中后景有遮挡与层次；不挡门、信箱；检查模型面数、贴图与加载体积 |
| 4 产品集成 | 摄像机、热点、备用图统一；收信、写信、日历、音乐回归；部署验证 | 本地构建和相关回归通过；横竖屏备用图及热点一致；发布状态与线上资源核验 |

阶段之间先检查实际截图，发现结构偏差先改结构。阶段 1 不作为最终美术质量验收，不能因为构建通过就宣称还原完成。

## 实现与素材约束

- 先在现有 Three.js 中定量建模建筑，独立模块管理建筑坐标变换；保留后续替换为 GLB 的边界。
- 真实植物候选使用可核实授权的模型，先检查体积和面数再接入；不把数百万面的离线模型直接放进浏览器。
- 不依赖付费 AI 生成。新素材记录原始来源、授权及本地处理；优先 CC0。
- Poly Haven 的 Wood Planks 可作为木板纹理候选：https://polyhaven.com/a/wood_planks
- Poly Haven 的 Pine Tree 01 / Fir Tree 01 是待评估候选，尚未下载或接入；不代表已满足网页性能要求。
- 本地阶段稿与正式站版本分开说明；未验证的方案不自动发布。

## 用户协助

目前无必需的协助事项，也无需充值或新增 skill。其他视角或原始模型若以后获得可提供，但不是开工前提。隐藏空间按现有产品需求合理补全。若将来确需付费素材、第三方账号或外部模型制作，先列明资源、费用、授权与用途，再请求相应授权。
