# 批注回复验收

## 本地体验

运行开发服务后打开 `/preview.html`，点击底部「查看内容」。演示文字已包含粉色原批注、淡蓝色回复和浅紫色重叠区域。

1. 点开标记，通过左上角粉色、蓝色小圆点切换查看原批注与回复。便笺与现有批注使用相同的自适应尺寸、字体、圆角和右上角图标，只更换回复色系。
2. 选中另一段原文并右键，输入自己的想法后点击右上角对勾发送。
3. 也可以点开粉色批注，点击右上角的小铅笔回复，对相同的原文选区回复。
4. 关闭纸页，点击底部「切换为分享者」，再打开「查看内容」，检查对方视角能看到回复且不能编辑。
5. 本地演示回复保存在此浏览器中，刷新后仍保留。正文和原批注不应改变。

## 配色

| 用途 | 色号 |
|------|------|
| 分享者原批注 | `#F7D6D4` |
| 阅读者回复 | `#D6EAF5` |
| 双方重叠 | `#E3DDF1` |
| 回复便笺底色 | `#F4F9FC` |
| 回复便笺文字 | `#445E71` |

参考 [Radix Sky / Iris 色阶](https://www.radix-ui.com/colors/docs/palette-composition/scales)及其[背景选色原则](https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale)，再按现有米白纸张与粉色调整为低饱和蓝与浅紫。重叠区域按原文偏移切分并填固定色，不依赖透明叠加顺序。

## 发布顺序

本地验收通过后发布代码。正式数据库需按顺序执行：

1. `supabase/migrations/20261030090000_annotation_replies.sql`：新增批注回复及访问权限。
2. `supabase/migrations/20261030100000_remove_reaction_note_limit.sql`：移除普通文字回应的旧 20 字数据库限制。

普通文字回应和批注回复均不设字数上限。推送代码不会自动执行数据库 SQL；上线前应确认这两条迁移已执行。
