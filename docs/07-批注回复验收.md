# 批注回复验收

## 本地体验

运行开发服务后打开 `/preview.html`，点击底部「查看内容」。演示文字已包含暖金色原批注、鼠尾草绿回复和赭米色重叠区域。

1. 点开标记，通过左上角暖金色与鼠尾草绿小圆点切换查看原批注与回复。
2. 选中另一段原文并右键，输入自己的想法后点击右上角对勾发送。
3. 也可以点开暖金色批注，点击右上角的小铅笔，对相同的原文选区回复。
4. 关闭纸页，点击底部「切换为分享者」，再打开「查看内容」，检查对方视角能看到回复且不能编辑。
5. 本地演示回复保存在此浏览器中，刷新后仍保留。正文和原批注不应改变。

## 配色

| 用途 | 色号 |
|------|------|
| 分享者原批注 | `#F3DEB1` |
| 阅读者回复 | `#D7E6CC` |
| 双方重叠 | `#D4C69A` |
| 回复便笺底色 | `#EDF2E4` |
| 回复便笺文字 | `#32352A` |

重叠区域按原文偏移切分并使用固定的赭米色。

## 发布顺序

本地验收通过后发布代码。正式数据库需按顺序执行：

1. `supabase/migrations/20261030090000_annotation_replies.sql`：新增批注回复及访问权限。
2. `supabase/migrations/20261030100000_remove_reaction_note_limit.sql`：移除普通文字回应的旧 20 字数据库限制。

普通文字回应和批注回复均不设字数上限。推送代码不会自动执行数据库 SQL；上线前应确认这两条迁移已执行。
