## 第一步：先跑一个数据库脚本（必做，不做会报错）

阶段 6 加了「信里夹照片」和「回应」两个功能，需要数据库里多几样东西。

1. 打开 Supabase 控制台 → 左边找到 `SQL Editor`
2. 点 `New query`
3. 把项目里 `supabase/phase6-extras.sql` 的全部内容复制进去
4. 点 `Run`

应该看到：`Success. No rows returned`（绿色提示）。

它建立了三样东西：

| 东西 | 作用 |
|------|------|
| `letters.images` 字段 | 存这封信夹了哪几张照片 |
| `reactions` 表 | 存四种回应表情 + 一句话，一封信只能回应一次 |
| `letter-images` 存储桶 | 照片文件真正存放的地方 |

**如果不跑这个脚本**：写信时点「夹张照片」会失败，拆信后的回应也发不出去。

跑完可以顺手确认一下：Supabase 左边 `Storage`，应该能看到一个叫 `letter-images` 的桶。

## 第三步：逐项验收（正式界面）

### 3.1 窗台场景（阶段 4）

1. 打开首页，应该是**整屏的窗景**，没有黑边裁切，也没有滚动条
2. 窗外占了画面绝大部分，正对着窗户，看得见远处的小镇和湖
3. 把浏览器窗口拉宽拉窄，画面应该整体缩放，**不会把窗户切掉一半**
4. 鼠标移到桌上这些东西上，应该有轻微的亮起和放大：
   铃铛 / 信纸和笔 / 窗台的信封 / 台历 / 茶杯 / 台灯 / 相框（设置）
5. 窗台上有未读的信时，信封上会有一颗**火漆色的小封蜡点**在跳
6. 鸽子在你窗台时，站在窗沿上轻轻起伏；点它一下会有小动作和一句话
7. 鸽子守着信的时候，身边浮着**一封小小的牛皮纸信**（带一点红火漆）

### 3.2 四时光线（阶段 4）

现在的时段是跟着你电脑的真实时间走的，所以白天只能看到白天。
**想一次看全四个时段，用预览台**（见第四步），不用改系统时间。

规则是：

| 时段 | 时间 | 台灯 |
|------|------|------|
| 早晨 | 5:00 - 10:00 | 灭 |
| 白天 | 10:00 - 17:00 | 灭 |
| 黄昏 | 17:00 - 19:30 | 灭 |
| 夜晚 | 19:30 - 5:00 | **亮** |

夜晚要能看到：台灯亮着、桌上有三团暖光把信封和台历照出来、
天上有星星和月亮、窗外远处小镇有一片细碎的灯火。

### 3.3 仪式感（阶段 5）

1. 让对方寄一封信过来
2. 点窗台的信封 → 打开的是一只**封着火漆的信封**（火漆上是一根羽毛），不是直接的信纸
3. 点一下信封 → 火漆裂开、信封张口、信纸从里面升起来，有开信的声音
4. 已经读过的信再打开，就直接展开，不再重复拆封仪式
5. 写信点「让鸽子送去」→ 先盖一枚火漆印、听见翅膀声，才退场
6. 茶杯面板里切换 雨 / 风 / 炉火 / 鸟鸣，声音是程序现场合成的，没有音频文件
7. 摇铃铛：鸽子在你窗台时不用摇；在对方那儿时，会先征求对方同意

### 3.4 图片、回应、日历（阶段 6）

1. 写信时点「夹张照片」，最多 3 张，寄出去
2. 对方拆开这封信，照片以小拍立得的样子躺在信里，点一下能放大
3. 拆完信下面有**四个回应表情** + 一句话，选一个送出去
4. 回应只能送一次，送完就改不了了（这是故意的，数据库层面就锁住了）
5. 寄信的人再打开那封信，能看到对方的回应
6. 点台历 → 打开月历。**有信往来的那天，日期下面有一颗小红点**
7. 点有红点的那天，能翻出那天的信

## 第四步：美术预览台（重点，你会用得上）

`npm run dev` 之后，浏览器打开：

```
http://localhost:5173/preview.html
```

这个页面**不连数据库**，专门用来看画面。画面下方（黑边上）有一条控制条：

| 按钮 | 作用 |
|------|------|
| 早晨 / 白天 / 黄昏 / 夜晚 | 强制切换时段，不用等时间 |
| 鸽子在 / 鸽子不在 | 切鸽子在不在你窗台 |
| 守信 / 空闲 | 切鸽子有没有守着信（守信时身边有小信封） |
| 热区 | 打开后，七个物件的点击范围会画成红框 |
| bell / write / letters / calendar / cup / settings | 逐个打开六个面板 |
| 拆信 | 播一遍完整的开信仪式 |

注意：按钮上显示的是**当前状态**，不是「点了会变成什么」。
比如它写着「守信」，意思是现在正守着信。

## 第五步：这一轮我做的取舍，需要你拍板

### 5.1 黄昏做不出「橘色的云」（最需要你决定的一条）

我们现在四个时段**共用同一张正午的背景图**，靠 CSS 滤镜调出早晚。

我试了很多种办法（色相旋转、老照片色调、橘色霞光叠加），结论是：
**从一张正午的图，用滤镜伪造不出真正的日落**。
把橘色加重，天空会变青绿或者整张图变成一张老照片，就丢掉了你要的「明亮鲜艳充满希望」。

所以现在的黄昏是「太阳把整间屋子照成了蜜糖的颜色」——屋里暖，
但**天空还是白天的蓝**。小诗的措辞我也改了，不给画面开空头承诺。

**真正的解法**：请你在 ChatGPT 里生成三张新的背景图（早晨 / 黄昏 / 夜晚），
构图要和现在这张 `public/bg-window-day.jpg` **完全一样**（同一个机位、
桌上东西的位置不变），只改光线。这样热区坐标一个都不用重新对。

拿到图之后告诉我，我改两行代码就能换上（把 `filter` 和 `overlay` 关掉，直接用原图）。

提示词我写好了，直接用：

**黄昏那张：**

```
和上一张图完全相同的场景、完全相同的机位和构图（同一间屋子、同一扇打开的
窗户、桌上同样的台灯、书、信封、台历、茶杯、花瓶），只把时间改成日落时分。
天空是橘红与玫瑰金的晚霞，云被染成橘色，太阳低低地压在远山那一端，
金色的光斜斜地穿过窗户铺在书桌上，屋内是温暖的蜜糖色。
明亮、鲜艳、充满希望，不要压暗，不要老照片色调。手绘水彩风格，横向 16:9。
```

**早晨那张：**

```
和上一张图完全相同的场景、完全相同的机位和构图，只把时间改成清晨。
天空是清澈的淡蓝带一点粉，远处的湖面和小镇上浮着一层薄薄的晨雾，
第一缕金色的阳光从右上方斜射进窗户，空气干净透亮，露水感。
明亮、鲜艳、充满希望。手绘水彩风格，横向 16:9。
```

**夜晚那张：**

```
和上一张图完全相同的场景、完全相同的机位和构图，只把时间改成夜晚。
窗外是深蓝的夜空，满天繁星和一轮月亮，远处小镇的窗户亮着一片温暖的
细碎灯火，湖面有月光的反光。屋内台灯是亮着的，暖黄的光照亮书桌上的
信封、台历和茶杯，屋子里有安全温暖的感觉。夜色要通透，不要死黑一片。
手绘水彩风格，横向 16:9。
```

### 5.2 我把界面上的大 emoji 全换成了手画图标

原因：emoji 在 Windows / Mac / 手机上长得完全不一样，而且尺寸小的时候会糊成一个色块。
最典型的是鸽子身边那个 ✉️ ——它在亮亮的天空上就是**一个没有意义的白方块**，
我在实测截图里一眼就看出来了。

换掉的地方：

| 位置 | 原来 | 现在 |
|------|------|------|
| 鸽子守信时身边 | ✉️ | 手画牛皮纸小信 + 红火漆 |
| 铃铛面板 | 🔔 | 手画黄铜手铃（木把手 + 铜箍 + 高光 + 铃舌） |
| 「有铃声」弹窗 | 🔔 | 同一只黄铜手铃 |
| 茶杯面板 | 🍵 | 手画青花瓷杯（一枝梅 + 弦纹 + 茶汤高光） |
| 环境音五个选项 | 🍵🌧️🍃🔥🐦 | 统一线条风格的细线图标 |
| 火漆印上 | 🕊️ | 手画羽毛（寻常的标记） |
| 领养鸽子那一页 | 🕊️ | 直接用真的那只鸽子立绘 |
| 台历上有信的日子 | ✉️ | 一颗火漆色小红点（规则里写的就是「打点」） |
| 右上角的静音按钮 | 🔈（彩色） | 白细线的小喇叭加一个叉 |
| 右上角的设置按钮 | ⚙（系统字符） | 手画八齿齿轮，和小喇叭同一套笔画 |
| 信封上的未读提示 | 亮红色小圆点 | 火漆色小封蜡 |

**保留 emoji 的只有一处**：四种回应表情（☕❤️👍🐶）——产品规则里明确要求的，
而且实测在这台机器上渲染正常。

### 5.3 顺手修的一个真 bug
