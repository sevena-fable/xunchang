# 02 · 功能规则(定稿)

本文档是所有已敲定功能规则的权威版本。开发时以此为准。

---

## 1. 用户系统与配对

- 注册/登录:**邮箱 + 密码**(Supabase Auth)
- 用户设置自己的昵称
- **配对流程**:
  1. A 注册后生成唯一邀请码
  2. B 注册后输入邀请码,加入 A 的空间
  3. 配对成功后,两人看到**相同的领养动画**,获得一只共同的信鸽
- 一个空间只有两个人;一人只加入一个空间(多关系扩展留待未来)

## 2. 鸽子的领养与命名

- 鸽子的**名字**:两人共同商定,全空间共享一个名字
- 鸽子**对各自的称呼**:各自独立设置(比如它叫 A"姐姐",叫 B"笨蛋")

## 3. 信鸽状态机(核心)

### 3.1 位置规则

- 鸽子**只存在于两个地方**:A 的窗台 或 B 的窗台
- 上线看不到鸽子 = 它此刻在对方那里(位置本身就是提示,无需任何"小红点")

### 3.2 三种状态

| 状态 | 含义 | 行为 |
|------|------|------|
| **空闲** | 无任务 | 可被召唤、可互动、会自主溜达 |
| **送信中** | 叼着信飞往对方窗台 | 短暂的过渡状态(飞行动画) |
| **守信** | 停在收信人窗台,身边有未读信 | 不主动溜达,守着信等收信人;仍可被写信人召唤走 |

### 3.3 召唤规则(摇铃)

召唤**必须由用户主动触发**(摇铃),系统在任何情况下都不会自动召唤。

| 场景 | 结果 |
|------|------|
| 鸽子在自己窗台 | 无需召唤,直接互动/寄信 |
| 鸽子在对方处,对方**在线** | 对方收到提示,**同意**后鸽子飞回;**拒绝**则召唤失败 |
| 鸽子在对方处,对方**离线** | 直接召唤成功,鸽子飞回 |

### 3.4 守信规则

- A 寄信给 B,鸽子送达后进入**守信**状态:停在 B 的窗台守着信,不自主溜达
- 守信期间 A 仍可摇铃召唤鸽子(走 3.3 召唤规则)
- **直到 B 读了信**,鸽子才恢复空闲、可自由溜达
- 若 A 只是把鸽子召唤过来玩(没有寄信),当 A 下线后,鸽子会自主溜达——且**更大概率飞回 B 处,继续守着那封未读的信**

### 3.5 溜达规则(自主生命感)

- 空闲状态下,鸽子会自己在 A、B 窗台之间随机"溜达"
- 有未读信等待时,溜达的方向偏向收信人一侧(见 3.4)
- 具体溜达频率/概率为可调参数,开发时定初值再体验调优
- 设计意图:鸽子是承载这段关系的小生命,未来版本考虑接入 AI 人格

### 3.6 互动(MVP 范围)

- 点击鸽子 → 随机播放小动作(歪头、理毛、咕咕叫、蹭你等),纯氛围陪伴
- 喂食、成长值等养成系统 **不在第一版**

## 4. 信件系统

### 4.1 写信与寄信流程

1. **随时可写**:写好后"封存",信封放在自己桌上(未寄出状态)
2. **寄出必须摇铃召唤鸽子**(走召唤规则),鸽子在场才能叼信飞走
3. 鸽子叼信飞往对方窗台(送信中 → 守信)

### 4.2 送达表现

| 场景 | 收信人看到什么 |
|------|----------------|
| 收信人**在线** | 播放鸽子飞来的动画,信落在桌上 |
| 收信人**离线**,期间鸽子未被召走 | 上线直接看到:鸽子在自己窗台 + 桌上新信封(不播飞来动画) |
| 收信人**离线**,期间鸽子被写信人召走 | 上线只看到桌上的新信封 |

- 对方桌上可以堆**多封未读信**
- **不做签收环节**

### 4.3 信件内容(MVP)

- **文字 + 图片**
- 链接分享与预览卡片 → 第二版(需要服务端抓取,技术较重)

### 4.4 信纸

- 提供 **3~5 款信纸**供写信时选择(参考:米白、淡蓝、牛皮纸、夜空)
- 对方开信时看到同款信纸

### 4.5 开信体验

- 点击桌上信封 → 开信动画 → 信纸展开 → 看到内容
- **第一版不做信件 BGM**(歌曲版权与来源问题留待后续);氛围由**环境音**承担(见 6.4)

## 5. 回应系统

- **只有收信人**可以对信回应;任何人不能回应自己写的信
- 回应内容:**(一个表情,可选)+(20 字以内短评,可选)**
  - 表情限四种:☕ 咖啡(下次聊聊)、❤️ 爱心(喜欢)、👍 点赞、🐶 狗头
- 回应提交后,**这封信的互动彻底结束**:写信人不能回复对方的回应,回应不可修改
- 回应**即时同步**显示在信件上,不占用鸽子运送(鸽子只运正式的信)

## 6. 窗台场景

### 6.1 视角与构图

- 第一人称视角,**只能看到自己的窗台**;对方的存在感通过鸽子位置、来信、回应间接传递
- **横屏构图,电脑优先**

### 6.2 四时画面

- 画面时间与**现实时间匹配**,第一版做 4 张固定场景画面(不做光线渐变):
  - 早晨 / 白天 / 黄昏 / 夜晚
- 时间区间(默认值,可调):早晨 5:00–9:00,白天 9:00–17:00,黄昏 17:00–19:30,夜晚 19:30–次日 5:00
- 季节变化 → 第二版

### 6.3 物件与功能映射

| 物件 | 功能 |
|------|------|
| 🔔 铃铛 | 召唤鸽子 |
| 🖋️ 钢笔 + 信纸 | 写信 |
| ✉️ 桌上的信封 | 读信(未读的信摆在桌上) |
| 📅 墙上挂历 | 打开回忆日历 |
| 💡 台灯 | **自动**:白天不亮,晚上亮(不是手动开关,是场景的时间语言) |
| ☕ 茶杯 | 环境音开关 |
| 📚 书 | 第一版纯装饰,留作未来扩展入口 |

### 6.4 环境音

- 免版权环境音若干:雨声、风声、炉火、鸟鸣
- 通过茶杯开关/切换

## 7. 日历回忆

- 月视图日历,**有通信的日子自动标记一个小信封**
- 点击日期可翻看当天的信
- 纯自动沉淀,零操作成本;手动添加纪念日 → 第二版

## 8. 待定细节(开发时再定)

- 召唤许可弹窗若对方一直不响应:建议超时(如 60 秒)视为召唤失败,可再次尝试——**待体验后确认**
- 溜达的具体频率与概率参数
- 领养动画与开信动画的具体分镜
