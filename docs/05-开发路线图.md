# 05 · 开发路线图与学习地图

原则:**每个阶段都产出一个看得见、用得上的东西**,持续获得正反馈;每个阶段附带你会学到的编程概念。

---

## 阶段 0:环境搭建与部署空壳(约 3~5 天)

**目标**:让一个页面从你的电脑跑到互联网上。

- 安装 Node.js、Git
- 用 Vite 创建 React 项目,装 Tailwind CSS
- 注册 Supabase,创建项目;注册 Vercel
- 部署一个显示「寻常」的占位页到公网

**产出**:一个真实的网址,打开就是你的产品名
**学到**:前端项目长什么样、代码如何变成网站、部署是怎么回事

---

## 阶段 1:账号、配对与领养(约 1~2 周)

**目标**:两个人能注册、配对、拥有一只共同的鸽子。

- Supabase Auth 邮箱+密码注册/登录、昵称设置
- 创建 profiles / pairs / pigeons 表 + RLS 策略
- 邀请码生成与加入流程
- 领养动画(简版即可)、鸽子共同命名、各自称呼设置

**产出**:两个账号配对成功,看到同一只有名字的鸽子
**学到**:数据库表与关系、用户认证、React 状态管理

---

## 阶段 2:信件核心流程(约 1~2 周)

**目标**:跑通"写信 → 寄出 → 送达 → 读信"闭环(先不管美术和复杂动画)。

- letters 表 + RLS
- 写信(先纯文字)、封存、寄出(本阶段先简化:鸽子即时到场)
- 收信、读信、已读状态
- 接入 Supabase Realtime:对方在线时新信实时出现

**产出**:A 写信,B 的页面实时收到——产品的心脏开始跳动
**学到**:增删改查(CRUD)、实时推送、数据安全(RLS)

---

## 阶段 3:信鸽状态机(约 1~2 周)

**目标**:鸽子"活"起来,严格实现功能规则文档第 3 节。

- 鸽子位置与状态(空闲/送信中/守信)
- 摇铃召唤:对方在线需许可(summon_requests + 实时弹窗)、离线直召
- 守信规则:送达后守信,读信后释放
- 溜达:惰性结算 + 概率偏向未读信一侧
- 在线状态(Presence)

**产出**:鸽子有了自己的位置、脾气和情义
**学到**:状态机思维(编程最重要的思维之一)、边界条件处理

---

## 阶段 4:窗台场景与美术(约 1~2 周)

**目标**:从"功能原型"变成"治愈系产品"。

- AI 生成美术:窗台四时景(早晨/白天/黄昏/夜晚)、Q版奶油白信鸽、桌面物件
- 场景按现实时间切换画面;台灯白天灭、晚上亮
- 物件功能入口:铃铛/钢笔/信封/挂历/茶杯/书
- 鸽子在场景中的位置呈现(窗台上 / 不在)

**产出**:打开网站就是你梦想中的那扇窗
**学到**:美术资源管理、条件渲染、图层与布局

---

## 阶段 5:仪式感打磨(约 1~2 周)

**目标**:把关键时刻做成值得期待的仪式。

- Framer Motion:鸽子飞来/飞走动画、开信动画(信封展开)
- 信纸选择(3~5 款)
- 环境音(雨/风/炉火/鸟鸣)+ 茶杯开关(Howler.js)
- 点击鸽子的随机小动作

**产出**:开一封信,像拆一份礼物
**学到**:声明式动画、音频控制、微交互设计

---

## 阶段 6:图片、回应与日历(约 1~2 周)

**目标**:补全 MVP 的最后三块。

- Supabase Storage:信里传图片、点击放大
- 回应系统:四种表情 + 20 字短评、一次性、即时同步
- 日历:月视图、通信日小信封标记、按日期翻信

**产出**:完整的 MVP
**学到**:文件上传与存储、约束设计(唯一回应)、日期处理

---

## 总时间预估

每天投入 1~2 小时:**约 2~3 个月**。不用赶,每个阶段结束时做三件事:

1. **回顾**:这个阶段学到了什么新概念?
2. **重构**:有没有写得别扭的地方?整理一下
3. **记录**:写几句踩坑笔记(存回你的 Obsidian,就是你的技术博客雏形)
