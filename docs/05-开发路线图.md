# 05 · 维护方向

当前项目的使用流程是：**摘录文字 → 附出处与批注 → 分享 → 阅读与回应 → 按日期回看**。

本文记录围绕该流程的维护方向，不将旧阶段编号或尚未实现的想法作为当前功能承诺。

## 优先保持的体验

- 原文的段落、空行、标点与中文输入保持完整。
- 长内容翻页和阅读时的批注定位准确。
- 出处能方便补充，自己的想法与原文关联清楚。
- 草稿保存、照片读取、分享确认和回应失败时有明确反馈。
- 台历能找到未读内容，并可靠回看已经分享的文字。

## 需要实际需求再决定的方向

| 方向 | 先需要弄清的问题 |
|------|------------------|
| 搜索与整理 | 按正文、作品、作者还是标签查找最有用 |
| 出处结构化 | 是否需要单独管理作者、作品、链接和页码 |
| 跨设备草稿 | 如何同步正文、照片和批注，并处理并发编辑 |
| 手机阅读与编辑 | 如何在窄屏中兼顾文字、翻页和批注 |
| 历史代码清理 | 哪些旧模块可独立移除，哪些仍有数据迁移依赖 |

以上方向尚未实现，也没有排定发布日程。

## 每次修改的完成条件

1. 产品介绍和功能说明与本次实际行为一致。
2. 运行与改动相关的现有测试；涉及页面或构建配置时检查生产构建。
3. 涉及内容、批注、照片和空间权限时，核对跨账号可见性与重试行为。
4. 新增数据结构时提供升级顺序，保留现有内容的读取兼容。
