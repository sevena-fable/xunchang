# 03 · MVP 边界

第一版(MVP)的目标:**两个人可以真正用起来**——配对、养鸽子、写信、收信、回应、翻回忆。

## ✅ 第一版做

| 模块 | 内容 |
|------|------|
| 账号 | 邮箱+密码注册登录、昵称 |
| 配对 | 邀请码生成与加入、领养动画 |
| 鸽子 | 共同命名、各自称呼、完整状态机(位置/召唤/守信/溜达)、点击互动小动作 |
| 信件 | 写信(文字+图片)、信纸选择(3~5款)、封存、摇铃寄出、送达动画、开信动画、已读 |
| 回应 | 四种表情 + 20字短评(均可选)、一次性、即时同步 |
| 日历 | 月视图、通信日自动标记、按日期翻看信件 |
| 场景 | 横屏窗台、四时画面(早晨/白天/黄昏/夜晚,匹配现实时间)、台灯自动亮灭、物件功能入口 |
| 氛围 | 免版权环境音(雨/风/炉火/鸟鸣),茶杯开关 |
| 美术 | AI 生成:吉卜力感窗台四时景、Q版奶油白信鸽、桌面物件、信纸 |

## ⏸️ 暂缓(第二版及以后)

| 功能 | 说明 |
|------|------|
| 信件 BGM / 歌曲分享 | 版权与音源方案待定 |
| 链接分享 + 预览卡片 | 需要 Edge Function 服务端抓取 |
| 手动添加纪念日 | 日历第一版只做自动沉淀 |
| 鸽子喂食/养成/成长值 | 第一版互动仅为氛围动作 |
| 鸽子皮肤、鸽子窝 | IP 延展 |
| 季节变化、光线渐变 | 第一版只有四张固定画面 |
| 探望对方窗台 | 第一版只能看自己的 |
| 签收环节 | 明确不做,没想好怎么加 |
| 房间装饰 | — |
| 天气系统 | — |
| 鸽子 AI 人格 | 长期方向,架构上预留 |
| 多关系扩展 | 目前严格 1 对 1 |
| App 版本 / 手机深度优化 | Web 电脑优先,先跑通 |

## 判断新想法是否进 MVP 的原则

1. 不影响"写信—送信—读信—回应"核心闭环的,一律先放暂缓清单
2. 增加数据库复杂度或需要服务端功能的,优先推后
3. 纯前端氛围增强(动画、音效)可视工作量灵活插入
