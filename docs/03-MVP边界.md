# 03 · MVP 边界

当前目标：**把日常读到的文字摘录下来，附上出处和想法，分享、阅读并按日期回看。**

## 当前范围

| 模块 | 已实现的能力 |
|------|--------------|
| 账号 | 邮箱注册、登录、昵称、密码找回与重置 |
| 空间 | 邀请码配对，两人的阅读分享空间 |
| 分享 | 纯文字摘录、可选出处、最多 3 张照片 |
| 批注 | 分享前对原文选区添加、修改、删除批注，分享后查看 |
| 草稿 | 当前浏览器保存、多窗口编辑保护、失败后重试确认 |
| 阅读 | 整页排版与翻页、查看原文批注、照片放大、已读记录 |
| 回应 | 原文选区的批注回复；普通表情及 / 或文字回应，每条内容一次 |
| 台历 | 未读列表、旧版未分享内容列表、按日期回看 |
| 桌面 | 固定背景、纸笔与台历入口、设置与背景音乐 |
| 本地预览 | 使用演示数据体验分享、阅读与面板，无需后端 |

## 当前尚未提供

- 公开内容广场、关注关系、群组和多人空间。
- 全文搜索、标签、书单或按作品与作者筛选。
- 书籍与文章的自动导入、OCR、网页抓取、链接预览卡片。
- 独立的出处数据表或引用管理系统。
- 跨设备同步草稿。
- 分享后的正文修改、删除，或回应的多轮对话。
- 原生 App 和完整的手机端纸页编辑体验。

## 历史功能的处理

领养、信鸽、摇铃召唤、送信仪式、四时场景和环境音切换均不在当前页面流程中。仓库保留部分旧代码、资源和数据库兼容结构，保留这些文件不代表重新规划这些功能。

## 判断后续工作的依据

1. 是否有助于保存原文、说明出处、记录理解、方便阅读或回看。
2. 是否能让当前的分享流程更清楚、更可靠。
3. 需要新增数据结构或改变现有使用方式的功能，应先明确需求，再纳入开发。
