# 01 · 产品概览

## 名称

**一羽 · Double Serenity**

- 中文名「一羽」:一根羽毛,一只鸽子,两个人共同拥有的那"一"只。命名原则是含蓄——名字本身不提"两个人",也不直说"鸽子送信",懂的人自会会心一笑。
- 英文名 Double Serenity:两处安宁。

## 定位

治愈系**双人**通信空间。

- 只为两个人服务:一个空间里永远只有 A 和 B
- 低频、温柔、私密:反即时通讯,重仪式感
- Web 起步,未来发展为 App

## 核心世界观

> 两个独立窗台 + 一只共同信鸽 + 一套信件回忆系统。

- 每人拥有自己的**窗台**(第一人称视角):固定的窗户、窗外的树、桌上的物件
- 两人共同领养**一只信鸽**,信件由它叼着往返于两扇窗之间
- 时间在日历上留下两人通信的**回忆**

## 核心理念:鸽子是一个小生命

鸽子不是一个"功能",而是承载这段关系的小生命,它有自己的意志:

1. **它不被系统自动调度**——召唤必须由人主动摇铃,系统永远不会替你召唤它
2. **它有自己的行动**——空闲时会自己在两个窗台之间"溜达"
3. **它有情义**——送完信会守着那封没被读的信,等收信人回来
4. **它的位置本身就是两人之间的无声联系**——上线看不到鸽子,就知道它此刻在对方那里
5. 未来版本考虑为鸽子接入 AI,让它真正"活"起来

## 情感基调

- 视觉:温暖手绘动画风,吉卜力感(参考方向),自然、治愈、唯美可爱、有生命感
- 信鸽形象:圆润 Q 版、奶油白、柔软羽毛,可爱但不幼稚,温柔 + 调皮,陪伴型角色
- 交互:克制。回应只有四种表情和 20 字短评;看不到对方的窗台,但处处感受得到对方的存在

## 目标平台

- **电脑优先**:窗台场景按横屏构图设计,追求大窗台的空间感
- 手机端为次要适配(后续优化)
- 界面语言默认中文
