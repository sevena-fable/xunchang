# 01 · 产品概览

## 寻常是什么

寻常是一个分享日常阅读中遇到的文字的网站。

一本书里的一段话，一首诗里的几行，一篇文章里让人停下来的句子：摘录下来，附上出处，也记下自己读到这里时的想法，再分享给对方。

项目名为「寻常」，仓库与包名为 `xunchang`。介绍语：**读到喜欢的文字，分享给你。**

## 核心体验

1. 从桌面上的纸笔进入「给你看看」，输入或粘贴想分享的文字。
2. 用「加出处」记录作品与作者、链接或页码。
3. 选中某一句并右键添加批注，把原文和自己的想法联系起来。
4. 如有需要，附上照片，再点击「分享给对方」。
5. 对方在台历中找到内容，翻页阅读、查看批注、留下回应。
6. 日后按日期重新翻看这些摘录。

## 当前使用方式

- 邮箱注册、登录，通过邀请码建立两人的分享空间。
- 文字和照片在配对双方之间可见。
- 分享前的草稿保存在当前浏览器，可继续编辑。
- 纸页阅读与编辑以电脑浏览器为主，需要至少 900 × 600 的视口。

## 视觉与氛围

主界面是一张固定的窗边阅读桌面：落日、窗帘、花瓶、烛光、纸笔与台历。纸笔进入分享，台历进入回看，右上角进入设置。

纸页承载原文，淡色标记连接批注，面板采用奶白与灰紫色调。背景音乐由使用者自行选择是否播放。

## 介绍与界面文案

- 围绕「读到的文字」「摘录」「出处」「批注」「分享」「阅读」「回应」「回看」描述产品。
- 「给你看看」是分享入口；纸张与翻页是内容的呈现方式。
- 功能说明应对应当前可操作的界面，未接入页面的历史模块不作为现有能力介绍。
