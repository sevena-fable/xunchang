# 06 · 使用与验收

本清单对应当前的阅读分享网站。环境准备与完整 SQL 顺序见 [README](../README.md)。

## 1. 无后端预览

运行 `npm ci`、`npm run dev`，打开 `http://localhost:5173/preview.html`。

- 页面为固定的窗边阅读桌面，缩放窗口时保留完整构图。
- 底部「热区」按钮可以显示纸笔与台历两个入口的范围。
- 底部「分享」「台历」「设置」「查看内容」可以直接体验相应界面。
- 预览使用演示摘录；新分享与回应只在当前页面内存中演示，刷新后恢复初始数据。
- 编辑中的草稿仍保存在当前浏览器，并与正式页面隔离。

## 2. 分享一段阅读摘录

1. 打开「给你看看」，粘贴一段文字，保留原来的换行、空行和标点。
2. 输入足够长的内容，通过纸页左右按钮翻页，确认文字没有遗漏。
3. 点击「加出处」，填作品与作者、链接或页码，插入后应出现在正文末尾。
4. 再次打开出处面板并取消，正文不应改变。
5. 选中一句原文并右键添加批注，保存后应有淡色标记。
6. 点开标记修改或删除批注；较长的批注应完整保留。
7. 加照片并预览、移除；最多 3 张，每张不超过 6MB。
8. 点击「分享给对方」后可在台历找到内容，并继续编辑下一条。

## 3. 草稿与窗口

- 输入正文、加入批注和照片，关闭面板再打开，草稿应保留。
- 刷新页面后应能在同一浏览器继续编辑草稿。
- 同一草稿在两个窗口打开时，一个可编辑，另一个显示只读提示。
- 保存失败时应保留当前文字并显示失败提示。
- 分享结果待确认时应能重试确认，不产生重复记录。
- 小于 900 × 600 的视口应提示放大或全屏；放大后内容应恢复。

## 4. 阅读、回应与台历

1. 从「还没看过」或有红点的日期打开内容，应直接看到纸页。
2. 通过翻页按钮或 PageUp / PageDown 读完整段文字。
3. 点开批注查看想法，阅读者不能修改分享者的批注。
4. 点击照片放大，再关闭；照片失败可单独重试。
5. 选中原文并右键添加批注回复，核对淡蓝标记及与原粉色批注重叠的浅紫标记；也可继续使用普通表情与可换行的文字回应。详见 [批注回复验收](07-批注回复验收.md)。
6. 切换月份和日期，核对列表内容与日期。
7. 旧内容若出现在「还未分享」，可查看并确认分享。

## 5. 正式页面的双账号检查

完成 Supabase 配置和全部迁移后，用两个隔离的浏览器会话分别登录：

- 一方创建空间，另一方输入邀请码，配对后进入主页。
- 一方分享摘录、出处、批注与照片，另一方能够看到。
- 对方打开后已读状态保存，回应能同步给分享者。
- 与空间无关的第三个账号不能读取该内容和照片。
- 设置中可修改昵称、看到对方昵称，并播放或停止背景音乐。
- 验证密码找回和重置时使用自己的测试账号。

## 6. 自动验证

```bash
npm run build
npm test
```

现有测试覆盖逻辑、数据库权限和浏览器交互。Windows 浏览器测试默认使用 Edge；其他平台先运行 `npx playwright install chromium`。

单独运行逻辑与数据库权限测试：

```bash
node --test scripts/letter-logic.test.mjs scripts/letter-security.test.mjs
```
