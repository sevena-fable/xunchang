# Cabin materials

Local 1K texture maps downloaded from Poly Haven and encoded as WebP for the web scene.
The color, OpenGL normal, and roughness maps are used together.

- Plywood — https://polyhaven.com/a/plywood
- Bark Brown 02 — https://polyhaven.com/a/bark_brown_02
- Forest Ground 04 — https://polyhaven.com/a/forest_ground_04
- Wood Planks — https://polyhaven.com/a/wood_planks (added 2026-11-13 for reference reconstruction; 1K JPG diffuse/OpenGL normal/roughness converted to WebP; a single-board region is selected by UV transform)

All listed assets are CC0. https://polyhaven.com/license

The website serves the files locally. Material preparation used the Poly Haven public API.
